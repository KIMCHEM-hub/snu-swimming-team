# Seoul National University Official Swimming Team

서울대학교 공식 수영부의 로컬 정적 웹사이트입니다. HTML, CSS, Vanilla JavaScript만 사용합니다.

## 현재 구성

- `index.html` — 메인 및 ABOUT, TEAM, TRAINING, SCHEDULE, RECORDS, NEWS, GALLERY, JOIN 섹션
- `css/style.css` — 공통 반응형 스타일 및 접근성/감소된 모션 설정
- `js/main.js` — 모바일 메뉴, 헤더 상태, 기록 탭, 섹션 표시 동작
- `assets/images/` — 서울대학교 로고, 수영부 엠블럼, 히어로 수영장 이미지

## 로컬 미리보기

`index.html`을 브라우저에서 열어 확인합니다. 이 단계에서는 배포나 원격 저장소 작업을 진행하지 않습니다.

## 편집 안내

- `[대괄호]`로 표기한 모든 텍스트는 실제 팀 정보가 준비되면 교체합니다.
- 팀원은 `TEAM` 섹션의 `.member` 항목을 복제해 추가합니다.
- 주간 훈련은 `TRAINING` 섹션의 `.table-row`를 수정합니다.
- 일정, 기록, 뉴스와 갤러리의 자리표시자는 각 해당 섹션에서 실제 콘텐츠로 교체합니다.
- 모집 버튼은 현재 제공된 Google Forms 주소에 연결되어 있습니다.
